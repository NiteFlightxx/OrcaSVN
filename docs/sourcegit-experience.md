# SourceGit 操作与界面对齐（2026-11-10）

本轮参考本地 SourceGit 的 WorkingCopy、Popup、Histories、Conflict、StashesPage、LauncherTabBar 源码；保留 Vue/Tauri 和 SVN 行为。

## 已实现的交互

- 提交在工作区内打开审阅弹窗，不再跳转到另一份表单。标题、描述、最近说明与模板共用草稿。明确展示服务器目标、实际提交路径和被筛选隐藏的已选路径。未受控文件先 Add，显示展开后的实际路径，再由用户确认提交。失败保留草稿，成功只清除本次提交的选择；执行期间继续编辑的新草稿不会被旧结果清空。
- 提交、更新、检出、Switch、冲突处理、贮藏与丢弃共用操作忙碌状态。展示执行、刷新、完成、冲突及失败阶段。SVN 写命令同时读取 stdout/stderr，并以批次发布实时输出。命令结果与视图刷新错误分开；刷新失败不会把已经成功的命令当成可以重试的失败操作。
- 丢弃继续使用已有的精确状态补丁刷新，不增加自动备份、不改为全工作副本扫描。目录选择范围、另一个暂存面板及隐藏路径的保护仍由原有预检和后端复核执行。
- `.gitignore` 仅过滤未版本控制／忽略状态的路径。受 SVN 管理的内容和属性变更始终保留。工作区可临时显示隐藏项，面板显示可见／总数及提交范围。旧显示快照使用新的缓存版本，避免继续使用旧过滤结果。
- 工作区选中冲突文件后直接显示双方版本、当前结果和解决操作，完成后选中下一个冲突。属性／树冲突继续手工整理后确认。二进制文件展示路径、大小及外部差异工具入口。
- 外部工具在设置中配置绝对可执行文件路径及 JSON 参数数组。差异占位符为 `{left}`、`{right}`；合并为 `{base}`、`{mine}`、`{theirs}`、`{merged}`。使用原生进程参数，不经过 Shell。差异双方为保留原始字节的临时文件；只有合并结果指向工作文件。工具退出后仍需明确标记冲突解决。Windows 接受原生 `.exe`。显式比较生成的输入保留在应用缓存的 `external-tools/`，避免单实例工具的启动器提前退出后输入失效；这不是丢弃修改的自动备份。
- 历史列表与详情、变更文件与 Diff 均支持拖动分隔并保存尺寸。选中历史自动预览首个变更文件，可比较两个 revision 或当前分支的 revision 与工作副本。保留 SVN 分页和单次提交挑选，未添加 Git 提交拓扑或自动向服务器提交。
- Diff 支持统一／并排模式、上／下一个差异、文本搜索与属性差异。列表和 Diff 继续虚拟化。完整文件贮藏也使用同一 Diff 组件。
- 贮藏默认统一为记录列表、文件目录树和右侧预览，提供筛选、工具栏及右键动作。旧文本记录显示类型，支持显式迁移。原有文本分块操作保留在“旧版文本贮藏”工具弹窗，未删除存储数据或改写旧恢复规则。
- 每个仓库保存页面、查询、浏览分支、工作区选择和滚动位置；最近 20 个仓库的界面状态写入本机设置。暂存选择和草稿仍沿用原有按工作区与分支隔离的存储。支持标签拖动排序、中键关闭、关闭其他／右侧标签，写操作期间阻止切换仓库。
- 分支支持名称／路径排序与路径分组；完整 URL、收藏及普通 SVN Switch 行为保留。右键子菜单改为级联菜单，支持方向键和边界定位。页面共享控件尺寸、焦点框、紧凑行高与限高弹窗；文件 Diff 和 Blame 从上下文进入。
