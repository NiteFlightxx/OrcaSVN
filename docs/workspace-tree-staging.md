# 工作区目录树与 Staged / Unstaged

工作区的变更文件按实际相对路径组织为可展开目录树。上方为 Unstaged，下方为 Staged；两块独立滚动，仍使用虚拟列表，只渲染当前窗口内的行。

文件与分组目录均提供右键操作，具体入口及 SVN 适用范围见 [右键菜单说明](file-context-menu.md)。

- 单击文件查看右侧差异，完整相对路径保留在悬浮提示中。
- 单击文件夹或箭头展开/收起；顶部可全部展开/收起。展开状态按工作副本、分支和面板保存。
- 文件或文件夹右侧的 `+` 暂存、`−` 取消暂存。文件夹操作覆盖该面板当前目录下的可选变更，保留 SVN 原始路径。
- Stage All / Unstage All 只作用于当前列表显示且允许提交的路径；不会额外选入被状态筛选或 `.gitignore` 隐藏的文件。
- 上下键浏览，左右键展开/收起或返回父目录，Home/End 到首尾，空格暂存/取消暂存当前节点，Delete 进入当前节点的丢弃预览和确认。
- “审阅并提交”进入现有提交页；两处共享本次提交选择，提交页勾选会同步回 Staged。

SVN 没有 Git index。这里的 Staged 是按文件选择本次提交，不保存文件内容快照；文件后续编辑仍属于工作文件，提交读取当时的内容，不支持逐块冻结。界面一直显示该说明。

右侧 Diff 下方和提交页提供同一份“提交标题 + 详细描述”草稿。标题必填，描述支持多行并可留空；最终 SVN log message 为标题、一个空行和描述。工作区下方按钮进入提交页审阅 Staged 选择，然后由用户提交。草稿按工作副本和分支 URL 保存，切页或查看 Diff 不丢失；最近说明和合并模板可拆分填入两栏。提交失败或执行 Add 后待再次审阅时保留草稿，提交成功后仅清理实际提交且未被后续编辑的那份草稿。

Stage / Unstage 只改本地选择，不调用 SVN Add、Revert 或 Commit。未版本控制文件可以选入；提交页沿用原有 Add 后再次审阅的步骤，不在暂存时自动 Add。

选择按本地工作副本路径及分支 URL 隔离，并保存到本机。刷新不会自动清空它，也不会把新出现的文件自动暂存；只有新鲜、未过滤的 SVN 状态确认文件已干净或不再可提交时才移除对应选择。隐藏的 Staged 项会提示数量，不会因为显示过滤而默默遗失。切换工作副本/分支、提交成功或主动取消暂存均按对应范围处理。

仅用于分组的文件夹支持按实际目标批量丢弃；右键、目录行内按钮和 Delete 键共用预览、确认和重新验证流程。范围限定为该面板当前显示的目标，另一面板和隐藏修改受保护。实际 SVN 目录属性变更仍保留为独立目标，目录自身属性与子文件修改可以分别处理。完整操作边界见 [右键菜单说明](file-context-menu.md)。

源码主要位于 `WorkspaceChangeTree.vue`、`stores/staging.ts`、`utils/staging.ts`、`utils/changeTree.ts`。工作区保留原始 SVN 状态供选择验证，过滤后的状态继续供当前显示使用。现有提交页复用同一选择，不复制另一份选择状态。

验证包括目录分组与收起后的可见行、原始路径和目录属性、文件夹选择、跨分支/工作副本隔离、过滤不清空选择、未知缓存不触发清理、只提交已选路径，以及原有破坏性文件操作确认的回归。
