工作区的 Unstaged、Staged 两棵树均支持右键菜单。菜单采用分组行、分隔线、禁用状态和可展开“忽略”选项，并在窗口边缘自动调整位置。上下键、Home/End 可导航，Escape/Tab 关闭。

- 打开：使用系统默认方式打开现存文件或目录；资源关联由操作系统决定。
- 对比：进入 OrcaSVN 内置差异视图。当前没有外部 Visual Studio 差异工具配置，不显示一个无效的 Visual Studio 入口。
- 在资源管理器中显示、复制相对路径、复制完整路径：对文件及分组目录都有效。菜单内 Ctrl+C 复制相对路径，Ctrl+Shift+C 或 Ctrl+Alt+C 复制完整路径；文件列表和路径菜单会消费复制快捷键，其余位置仍屏蔽检查器快捷键。
- 追溯／时间线：对已版本控制的文本文件可用；二进制文件使用“历史”查看提交。
- 历史：读取被右击路径的 URL，而不是继续显示此前浏览的分支历史；可返回分支历史。文件/子目录历史中禁用挑选提交，避免把子树当成完整分支应用。
- 暂存／取消暂存：按所在面板变化。目录操作仅选择该面板的实际变更目标。全部操作仍遵守当前列表范围。
- 丢弃修改：文件与分组目录都可用，和目录行内按钮、Delete 键共用同一入口。只预览当前面板和筛选范围中的实际变更；确认框逐项显示“还原”或“删除”。确认前后检查状态、字节哈希、属性和分支，确认后直接执行，不创建自动备份。普通分组目录不会作为递归还原目标，不会顺带丢弃另一面板或被过滤的修改。
- 忽略：只允许未版本控制的路径，更新父目录 `svn:ignore`。支持精确名称和同扩展名，不改 `.gitignore`，也不隐藏已被 SVN 管理的修改。原有规则保留；忽略规则本身会成为父目录的待提交属性变化。
- 贮藏：把所点文件或该面板目录的变更带到完整贮藏检查页，检查后再保存，不在右击时直接清理工作文件。
- 保存为补丁：导出所选文本变更及目录自身属性，支持未跟踪的文本文件。二进制资产、未跟踪目录、非 UTF-8 和过大的文本需使用完整贮藏。输出需为新的 `.patch` / `.diff` 文件，不覆盖已有文件。选择包含二进制时整体拒绝，不留下一个假装包含资产内容的补丁。

打开菜单立即显示内容，本地元数据到达后更新可用项；迟到响应不能覆盖后来右击的目标。工作副本、分支变化或缓存状态未验证时，旧菜单不能执行相关写操作。忽略和补丁导出接入活动日志；后端重验来源 URL 并与该工作副本的其他写操作互斥。

状态尚未验证时，暂存、丢弃、贮藏和补丁提供禁用原因，并显示显式刷新入口。等待丢弃确认或执行期间禁止重复操作；取消、切换工作副本/分支、变更暂存选择或筛选都会使旧确认失效。执行成功或部分失败后均刷新真实状态；只有新鲜、未过滤的状态可以清理 Staged。

冲突文件会进入“处理所选冲突”弹窗，右键菜单也提供对应入口。可选择保留当前工作文件（`working`）、使用冲突发生时保存的本地版本（`mine-full`）或使用传入版本（`theirs-full`），点击应用前不执行。默认保留当前工作文件，包含冲突后继续编辑或重新编译的内容。文件及可用冲突材料沿用现有冲突处理后端完整备份；解决后刷新状态，不会自动提交，也不会接着丢弃普通修改。混合选择只处理所选冲突，其他修改保留。树与属性冲突必须手工处理并勾选确认，只允许标记当前结果；不会自动替换目录结构或属性。

弹窗取消、工作副本/分支变化和页面离开会使旧选择失效。批量处理逐项执行，部分失败保留已完成列表和备份，剩余冲突继续显示。根目录相对路径与从子目录打开的工作区分别映射，避免误选同名文件。

支持普通修改（含二进制）、属性修改、无历史的新增文件/目录、删除/缺失以及未跟踪文件/目录。新增目录要求完整选择其 SVN 子项；目录删除/缺失中被普通 SVN 状态折叠的隐含子项会展开到确认框，如包含受保护路径则拒绝。未跟踪目录会完整列出包括忽略文件在内的实际内容。复制/移动历史、替换、冲突、switched 子树、external、嵌套仓库和重解析点需分别处理，不会静默跳过。

丢弃操作不再复制文件、写入恢复清单或返回恢复目录，也不显示备份提示。已有的历史备份不清理。部分失败仍返回已完成路径及原始错误并刷新状态，不承诺事务回滚；目录删除只移除空目录，不递归删除确认后新出现的内容。贮藏与冲突解决属于独立流程。
