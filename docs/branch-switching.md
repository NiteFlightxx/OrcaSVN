# 分支列表与切换交互

参考本地 `E:\UnrealProjects\sourcegit` 中 `Views/BranchTree.axaml(.cs)`、`Views/BranchSelector.axaml`、`Views/Repository.axaml`、`Views/Checkout.axaml`、`ViewModels/Checkout.cs` 及 `Repository.CheckoutBranchAsync`：紧凑分组、独立的当前标记与选择、完整 URL 提示、右键菜单、明确的目标与工作副本状态。这里使用 SVN 的目录和 Switch 语义，不显示 Git 的本地／远端分支或 ahead/behind 字段。

- 收藏和普通分支分组，同一 URL 只显示一次。搜索匹配名称及 URL；当前标记与选中行分开。尾斜线去重，路径大小写保留，解码异常不使列表崩溃。
- 单击查看历史，双击、Enter、右键“切换”或底部按钮打开切换窗口。右键本身只打开菜单；提供收藏、复制 URL、浏览目录和从已保存列表移除。移除只影响本地记录，当前分支不可移除。
- 收藏沿用原 localStorage 键，旧收藏也进入可切换列表。当前分支会保存，切走后仍可找到；取消收藏保留对应保存记录。
- 加号打开完整 URL 输入，支持每行一个、分别验证。成功项保留，失败 URL 留在输入框供修正。`repository_branch` 只访问该 URL，并检查目录类型及同仓库 UUID。
- 目录浏览位于独立窗口，支持地址、上级、双击进入及选中后添加。侧栏只显示简短错误入口，完整详情可在窗口中展开；目录请求不阻塞身份、贮藏列表或已保存分支。父目录拒绝访问不视为单个分支被拒绝，也不视为认证成功。

切换窗口立即显示当前、目标和工作副本路径，随后调用只读预检查。检查通过后显示固定目标修订号，点击“切换”才调用 `repository_execute`。将保留的本地变更可展开查看，不禁用切换；目标访问错误和其他失败在窗口内显示，可重新检查。路径及详情限高滚动，关闭或工作区切换使迟到检查失效，执行按钮防止重复提交。

切换整个工作副本，外部工作副本不更新。默认保留本地修改，使用普通 SVN Switch 合并分支差异，不要求先提交或贮藏。预览显示将保留的变更，不承诺没有冲突；执行使用 `--accept postpone`，不使用 `--force` 或 `--ignore-ancestry`。文本、属性和树冲突以及无法合并的二进制冲突交给 SVN 标记，然后进入现有冲突页面。即使命令同时返回错误，也优先显示实际检测到的冲突。

弹窗保留查看工作区／打开贮藏入口，不自动提交、贮藏、丢弃或解决冲突。执行前重新检查身份、规范化后的 SVN 状态 XML、已修改受控文件内容及属性，以及工作副本数据库元数据；确认后发生变化则要求重新检查。未跟踪目录不递归扫描或复制，普通 Switch 交由 SVN 处理路径阻塞。Switch 不生成用于自动撤销的操作后内容快照。挑选提交继续要求干净工作副本，保留原预览、冲突和撤销规则。

验证：实际 Vue 组件在浏览器中使用明确的内存 SVN 夹具，确认本地变更提示不禁用切换，模拟执行同时返回错误和二进制冲突时仍进入冲突页面。此前分支 UI 夹具还覆盖父目录拒绝访问、当前标记、批量添加，并验证 1280×720 和 640×480 的限高弹窗。独立真实 SVN 仓库验证本地内容、属性、新增／删除调度、未跟踪目录和嵌套 Git 目录保留，同一文本文件不重叠修改自动合并，文本／二进制冲突保留，以及未跟踪文件阻塞不被覆盖。也验证了确认后修改内容或属性被拦截、挑选提交仍要求干净工作副本。浏览器夹具不等于真实服务器权限或原生窗口验收。未访问 用户工作副本 或用户 SVN 服务器。
