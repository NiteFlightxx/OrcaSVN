# OrcaSVN v0.6.5-rc.5

## 冲突处理

- 冲突页与本地更改共用文件树，支持 Ctrl／Shift 多选、全选和选择目录下的冲突文件。
- 右键直接选择使用冲突前的本地版本、传入版本，或保留当前处理结果并标记解决。
- 批量处理先确认路径和处理方式；文件版本替换会明确列出并跳过树与属性冲突。
- 树与属性冲突保留手动处理确认；内容冲突可调用外部合并工具。
- 显示当前处理文件、进度和失败路径，重试只处理未完成项。
- 缓存已读取的冲突详情，减少页面切换时重复加载。

## 验证范围

自动化回归使用隔离的合成 SVN 仓库；界面检查使用合成数据。各平台安装包的安装、启动和使用仍需分别验收。
