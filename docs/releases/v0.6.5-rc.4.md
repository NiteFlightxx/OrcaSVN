# OrcaSVN v0.6.5-rc.4

此版本为 NiteFlightxx/OrcaSVN Fork 的候选版本。

## 界面与交互

- 左侧采用 Fork 风格的文字导航、分支树和贮藏列表。
- 软件设置位于顶部“打开方式”右侧，设置弹窗分为常规、外观、SVN、外部工具和关于。
- 右键贮藏直接沿用选中的文件或目录范围，自动检查并显示只读确认列表，不再重复勾选。
- 更新工作副本立即显示进度、耗时、当前输出和命令日志，支持后台运行和重新打开进度。
- 更新完成、冲突和失败分别显示结果；后台失败时重新显示错误原因。

## 更新与发布

- 软件更新查询及下载链接指向 NiteFlightxx/OrcaSVN。
- 检查更新只提示公开正式版；没有正式版时显示没有更新。
- GitHub Actions 在三个平台全部通过检查和打包后公开候选版。
- 此 Fork 不向原项目的 WinGet 包提交更新。

## 验证范围

回归使用隔离的合成 SVN 仓库，不使用 用户工作副本。源码构建和自动化检查不能替代各平台安装包的实际安装、启动及使用验收。

## 下载

从此 Release 的 Assets 选择对应平台安装包。Windows 候选版使用 NSIS EXE；仍需本机 SVN CLI。
