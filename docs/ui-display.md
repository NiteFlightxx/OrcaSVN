## 固定导航与顶部区域

- 顶部依次为菜单、工具栏、仓库标签和内容区。菜单提供文件、视图和仓库操作，更新直接在当前页面执行。
- 工具栏左侧为刷新、更新和贮藏，中间为当前仓库及分支，右侧为打开方式、终端、外观及语言。
- 页面导航和分支合并为一列：本地更改、全部提交、分支筛选、收藏／已知分支、贮藏及检出。点击贮藏记录会打开对应条目。
- 侧栏默认显示，切换页面保持宽度和展开状态。用户可主动收起，并从视图菜单恢复导航。

## 本地更改

## 全部提交

- 提交列表和详情左右排列，详情不占用提交列表的垂直空间。

## 先确认整体 BASE，再处理不确定路径

- 使用配置的 SVN 安装旁的 `svnversion` 读取本地 BASE 最小／最大版本及 M／S／P 标志。只在确认范围完整、没有切换子树和稀疏检出时使用整体界限：提交版本不高于最小 BASE 为已包含，高于最大 BASE 为待更新；混合版本区间内继续逐路径判断。不会用根目录版本代替整个工作副本版本。
- M 标志可能只是普通文件编辑，首次需要时读取递归本地 info 元数据，验证所有节点有 BASE、schedule 正常、目录完整且 URL 仍属于本来源；存在新增／删除／替换等结构变化时不使用整体界限。判断始终针对 BASE，绝不覆盖未提交字节。
- 完整且已更新的工作副本能够确认删除文件、目录新增及替换的历史记录，不再因为目标文件不存在而一律未确认。稀疏、切换子目录、未提交结构变化、缺少 BASE、本地查询失败等返回具体原因；辅助工具不可用时退回逐路径检查，并在无法确认的记录中说明。
- 整体范围按工作副本、来源、配置的 SVN 程序和 `.svn/wc.db`／WAL／journal 的元数据指纹缓存，保留最近八个上下文；读取期间数据库或根来源／版本发生变化则拒绝旧结果。失败的范围读取不永久缓存。
- 前端状态刷新先调用仅查看数据库文件属性的轻量接口；指纹未变时复用 BASE 分类，不因普通文件状态列表变化重新扫描。外部 SVN 只更新子目录、根版本未变时，也会因数据库指纹变化重新判断。页面上下文、版本与操作 epoch 的旧响应保护继续保留。
