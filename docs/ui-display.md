# 界面精简与图标统一

本轮在现有工作流上调整显示，不改变 SVN Switch、提交范围、冲突恢复或丢弃策略。

## 布局

- 仓库名称集中在标签栏，去掉工具栏和侧栏的重复仓库标题。
- 顶部只保留刷新、更新、打开方式、当前分支和语言。提交在工作区右下角，贮藏从左侧页面栏进入。
- 工作区默认不常驻分支列，文件列表和 Diff 可直接使用这部分宽度。点击顶部当前分支或侧栏按钮按需展开；历史页默认保留分支导航。
- 去掉分支区单独的当前分支摘要、重复分组标题和底部重复 Switch 按钮；当前行保留勾选标记，双击、Enter、右键切换仍可用。排序选项折叠收纳。
- 文件筛选集中为一行，忽略项显示开关使用带说明的眼睛按钮。文件夹数量和 Staged/Unstaged 数量继续显示。
- 选中文件的路径、差异计数和属性／外部工具集中到 Diff 标题栏，减少多层工具条。紧凑提交编辑器用占位说明和可访问标签代替重复表单标题。
- 页面只保留自身的标题。贮藏只显示一条工具栏，旧版工具及导入入口收进更多菜单；外部工具设置作为设置页的折叠项。

## 图标

- 共享图标统一为本地 SVG，使用相同的 24px 网格、描边宽度和 `currentColor`，保留原组件导出名兼容现有调用。
- 移除 Material Symbols 字体依赖及约 5 MiB 的字体资源，避免字体未加载时显示图标英文名称。
- 字符箭头、星标、加减号等常用操作改用同套 SVG。页面导航、工具栏和右键菜单的图标尺寸分别统一。
- 文件按 UE 资产／二进制、源代码／配置、图片和普通文档区分图标，SVN 状态字母放到文件名右侧，继续保留状态文字及提示。
- 图标本身标为装饰，操作按钮保留可访问名称和 tooltip。窄窗口隐藏按钮文字时仍可识别其用途。
