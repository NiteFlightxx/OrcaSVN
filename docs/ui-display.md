# Fork 布局与界面交互

界面以用户提供的 Fork 截图为布局依据，继续使用 SVN 工作副本、版本号、分支 URL 和现有操作策略。本轮没有修改 Rust 后端。

## 固定导航与顶部区域

- 顶部依次为菜单、工具栏、仓库标签和内容区。菜单提供文件、视图和仓库操作，更新直接在当前页面执行。
- 工具栏左侧为刷新、更新和贮藏，中间为当前仓库及分支，右侧为打开方式、终端、外观及语言。
- 页面导航和分支合并为一列：本地更改、全部提交、分支筛选、收藏／已知分支、贮藏及检出。点击贮藏记录会打开对应条目。
- 侧栏默认显示，切换页面保持宽度和展开状态。用户可主动收起，并从视图菜单恢复导航。

## 本地更改

- 中间列表上方为 Unstaged，下方为 Staged；右侧为 Diff 和提交编辑器。
- 提交编辑器保留标题、描述、最近说明和模板；默认高度由 200px 调整为 160px，可拖动调整，最小 140px。
- 文件列表宽度、暂存分组比例、提交编辑器高度继续持久化。页面切换保留选择、筛选、滚动位置和提交草稿。
- SVN 的 Staged 仍表示本次提交范围，沿用现有提交审阅和文件操作逻辑。

## 全部提交

- 提交列表和详情左右排列，详情不占用提交列表的垂直空间。
- 右侧包含提交信息、变更和文件树三个标签，可通过方向键切换。默认显示作者、日期、版本、来源和完整提交说明，选择文件后才读取其差异。
- 变更列表和文件树共享选中文件及 Diff；文件双击可进入完整差异页面。文件树保留原始 SVN 路径、动作及目录／仓库根目录的属性变更。
- 历史列表比例、文件列表高度、选中版本、详情标签、文件路径、筛选与分页状态可保留。更换提交或关闭详情会使旧的异步差异请求失效。
- 作者及日期筛选收进筛选菜单，弹层限定在列表内，小窗口下不会被左侧边界裁切。

## 图标

继续使用统一的本地 SVG，使用 24px 网格、相同描边和 currentColor。文件按 UE 资产／二进制、代码／配置、图片及文档区分，状态文字与提示保留。装饰图标不进入按钮名称。

## 阅读显示调整

- UI 字体统一优先使用 Segoe UI Variable Text／Segoe UI，并提供 Microsoft YaHei UI／Microsoft YaHei 中文回退；不下载字体。文件和历史列表使用 14px，普通控件 13px，辅助文字主要为 12px。Diff 使用 13px 等宽字体和 22px 行高。
- 文件与历史行调整为 30px；虚拟文件列表同步使用 30px，Diff 的虚拟行高调整为紧凑 26px／普通 30px，避免字体放大后滚动和定位错位。
- 深色采用 Fork 中性灰背景与柔和文字，浅色采用暖灰背景；选中项、红绿差异、状态和文件夹图标使用统一的主题颜色。Diff 元信息降低字重，并移除逐行横线。
- 浅色、深色的主要文字、辅助文字、选中项、按钮和 Diff 配色对比度测试均达到至少 4.5:1。
- npm run check：前端 204 项通过；Rust 串行 118 项通过、3 项基准忽略。浏览器内存夹具验证深浅主题、800×600 窗口、2,000 项列表到底部以及实际字体／行高，无页面横向溢出。本轮未操作 ExampleWorkspace 或访问用户 SVN 服务。
